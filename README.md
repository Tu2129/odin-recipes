Odin Recipes

About the Project

Odin Recipes is a simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

The website contains a main page with links to different recipes. Each recipe page provides a description of the dish, a list of ingredients, and step-by-step instructions on how to prepare it.

The goal of this project was to practise the fundamentals of HTML by building a simple, multi-page website.

Skills Demonstrated

Through this project, I practised the following skills:

- Creating the basic HTML boilerplate and document structure.
- Using headings and paragraphs to organize content.
- Creating ordered and unordered lists.
- Adding images to web pages.
- Creating links between pages using anchor tags.
- Organizing website files and directories.
- Writing clean and readable HTML.

Technologies Used

- HTML5

What I Learned

This project helped me understand how to structure web pages with HTML, organize website content, and link multiple pages together to create a functional website.

It also strengthened my understanding of the fundamental building blocks of web development.
